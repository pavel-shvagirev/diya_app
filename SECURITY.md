# Политика безопасности

[English](SECURITY.en.md) · [Русский](SECURITY.md)

## Сообщить об уязвимости

Не создавайте публичный issue. Используйте приватное сообщение об уязвимости GitHub (вкладка
«Security» → «Report a vulnerability») в этом репозитории. Укажите версию, ОС и шаги
воспроизведения.

## Область и устройство

- Renderer работает в песочнице с изоляцией контекста и без доступа к Node; с главным процессом он
  общается только через типизированный мост `window.api`, и каждый IPC-обработчик проверяет свои
  аргументы.
- Сессия OAuth хранится зашифрованной через хранилище ключей ОС (Electron `safeStorage`); токены и
  подписанные ссылки скрыты в журнале.
- Токен доступа отправляется только на `https://cloud-api.yandex.net`; секрет приложения и
  refresh-токен — только на `https://oauth.yandex.ru` / `.com`. Секрет и сессия хранятся
  зашифрованными (`client-secret.bin`, `token.bin`). Больше никуда ничего не отправляется: нет
  телеметрии и иных серверов.
- Внешние ссылки открываются только для списка доменов Яндекса по HTTPS.
- Каждый IPC-обработчик проверяет, что отправитель — одна из собственных страниц приложения, и
  проверяет аргументы.
- Папкой синхронизации не может быть весь диск, домашняя папка, системная папка или папка данных
  приложения; символические ссылки не разворачиваются; ссылки передачи — только https; скачанное
  сверяется с размером и md5, которые сообщает Диск.
- Создание публичных ссылок в данный момент отключено (`FEATURES.publicLinks`) и отклоняется в главном процессе.
