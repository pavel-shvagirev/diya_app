## [Не выпущено]

### Добавлено

- Интерфейс файлового менеджера: дерево папок, таблица, панель инструментов, контекстное меню,
  корзина, строка состояния с квотой и живым прогрессом синхронизации и передач. Светлая и тёмная
  тема по системе, русский и английский.
- Вход через собственное приложение Яндекса: Client ID и Client secret (device flow), либо токен
  или адрес перенаправления. Секрет и сессия хранятся зашифрованными; идентификатор, секрет и
  токен приложения в программе не поставляются. Ссылки на Яндекс OAuth следуют языку интерфейса
  (.ru / .com); при отказе показывается код ошибки Яндекса. Руководство: `docs/SIGN_IN.md`.
- Язык интерфейса: русский или английский; по умолчанию язык системы, Настройки → Язык фиксирует
  выбор (меню, трей, окна и подпись конфликтных копий меняются сразу).
- Двусторонняя синхронизация папки с конфликтными копиями, защитой от удалений и постоянным
  состоянием синхронизации.
- Окно журнала (`Ctrl/Cmd+Shift+L`): категории, детальность, поиск; токены и подписанные ссылки
  скрыты.
- Трей; закрытие окна оставляет синхронизацию работать (`Ctrl/Cmd+W`); `Ctrl/Cmd+Q` требует
  второго нажатия, пункт меню «Завершить» выходит сразу.
- Значок приложения из собственного набора иконок проекта: Dock/окно, трей, установщики.
- Скачанные файлы сверяются с размером, md5 и объявленной длиной с Диска до того, как заменят
  что-либо.
- Контрактные тесты на официальных примерах ответов API (`tests/contract`); сквозной прогон
  против Диска в памяти (`npm run e2e`); `AGENTS.md`; шаблоны issue и pull request.
- Сборки для macOS (dmg, zip), Windows x64/arm64 (установщик, portable) и Linux x64/arm64
  (AppImage, deb, rpm) через
  GitHub Actions; CI с линтером, типами, тестами с покрытием, CodeQL, аудитом зависимостей.
- README: инструкция по автозапуску для macOS, Windows и Linux.

### Изменено

- Между запусками синхронизации проходит не меньше 5 с, кроме «Синхронизировать сейчас», которая стартует сразу (запуск дольше таймера в 60 с сразу
  сменялся следующим), а файл, на который Диск отвечает 5xx или 429, повторяется через 1 мин, 2, 4 …
  до 30 мин, а не на каждом запуске.
- Electron 45; better-sqlite3 13; electron-builder 26.
- Создание публичных ссылок отключено (существующие можно закрыть).
- Клиент API: таймаут на каждый запрос; чтения повторяются после сетевых сбоев, записи — нет;
  учитывается `Retry-After` (не дольше минуты); ошибки типизированы (`YandexApiError`).
- Передачи: пределы на соединение, на молчание и на ответ Диска; загрузка повторяется после
  500/503 и сбоев соединения; 413, 507 и 412 описаны словами; 202 считается «принято»; файлы
  больше 50 ГБ отклоняются до любых запросов.
- Ссылки на операцию распознаются в обоих видах из справочника (`/operations?id=` и
  `/operations/<id>`); опрашиваются только они.

### Безопасность

- IPC: каждый обработчик отклоняет сообщения от фреймов, не являющихся страницами приложения;
  все запросы разрешений браузера отклоняются.
- Папка синхронизации: целый диск, домашняя и системные папки и папка данных приложения
  отклоняются; символические ссылки не разворачиваются ни при загрузке, ни в синхронизации;
  ссылки передачи — только https.
- Linux: токены не сохраняются, если доступен лишь текстовый запасной вариант связки ключей.
- Сборки: фьюзы Electron (без `ELECTRON_RUN_AS_NODE`, `NODE_OPTIONS`, `--inspect`; только asar с
  проверкой целостности); сборки macOS подписаны ad-hoc; workflows не хранят токен checkout.

### Исправлено

- Загрузка файла могла обрушить всё приложение («A JavaScript error occurred in the main
  process», `assert(!this.paused)`): HTTP-клиент из Electron 45 падает, если сервер закрывает
  соединение, пока файл ещё записывается (nodejs/undici#5360). Запросы теперь идут через undici 8,
  где это исправлено.
- Загрузка отправляла пустое тело для маленьких файлов, из-за чего возникали цепочки конфликтных
  копий.
- Удаление файлов локально отклонялось как «массовое»; теперь переносится в корзину Диска.
- OAuth-токен мог уйти на чужой адрес при опросе операции.
- «Открыть» в трее падало после закрытия окна.
- Файл или папка, заменённые символической ссылкой, больше не удаляются с Диска.
- Зависшее соединение больше не замораживает синхронизацию.
