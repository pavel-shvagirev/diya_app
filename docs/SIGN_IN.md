# Вход: своё приложение Яндекса

В Diya нет идентификатора, секрета и токена приложения Яндекса. Яндекс пускает к Диску только
зарегистрированные OAuth-приложения: зарегистрируйте своё, один раз.
Программа работает с вашим Диском, а вы по [условиям API](https://yandex.ru/legal/disk_api/)
являетесь владельцем приложения.

## 1. Создайте приложение

Официальные руководства: [регистрация приложения](https://yandex.ru/dev/id/doc/ru/register-api) и
[доступ к API Диска](https://yandex.ru/dev/disk-api/doc/ru/concepts/quickstart#oauth).

1. Откройте <https://oauth.yandex.ru/client/new/> и войдите в аккаунт, чей Диск хотите использовать.
2. Тип: **Для доступа к API или отладки**. Название и контактный e-mail — ваши (название видите
   только вы).
3. Права (REST API Яндекс Диска): `cloud_api:disk.read`, `cloud_api:disk.write`,
   `cloud_api:disk.info`. (`cloud_api:disk.app_folder` не нужен.)
4. Создайте приложение. Яндекс покажет два значения: **ID** (`ClientID`) и **пароль**
   (`Client secret`). Скопируйте оба. Device flow требует оба значения для выдачи токена; путь через
   токен ниже в программе не нуждается ни в одном.

На экране входа есть кнопка **Открыть создание приложения** и те же шаги.

## 2. Войдите

Вставьте ID и секрет в поля **Client ID** и **Client secret** и нажмите **Сохранить**. Секрет
хранится зашифрованным хранилищем ОС в файле `client-secret.bin` (без хранилища — только на время
сеанса), больше нигде не показывается и отправляется только Яндексу. Дальше на выбор:

- **Войти через Яндекс** — программа покажет код (и скопирует его) и откроет страницу Яндекса
  «Device authorization»; вставьте код там и разрешите доступ. Это _device flow_ Яндекса
  ([описание](https://yandex.ru/dev/id/doc/ru/codes/screen-code-oauth)). «invalid_client» означает,
  что ID и секрет от разных приложений.
- **Токен** — нажмите **Открыть страницу токена**, разрешите доступ, скопируйте токен из адреса
  открывшейся страницы (после `access_token=` до `&`) и вставьте в поле токена; можно вставить
  и адрес целиком. Это [ручной токен](https://yandex.ru/dev/id/doc/ru/tokens/debug-token) Яндекса,
  для приложения указанного типа он работает всегда.

У токена, полученного вручную, ограниченный срок жизни (`expires_in` на той странице) и нет
refresh-токена; после истечения программа просит войти заново.

## Отзыв и удаление

- Отзовите доступ в настройках Яндекс ID (приложения с доступом к аккаунту) или удалите приложение
  на <https://oauth.yandex.ru/>.
- **Выход** в настройках Diya удаляет сохранённый токен. См.
  [где хранятся данные](../README.md#где-программа-хранит-данные).

## Для разработчиков

`YADISK_CLIENT_ID=<id> npm start` задаёт ID без ввода, `YADISK_CLIENT_SECRET` — секрет. Введённое
на экране приоритетнее переменных. В релизных сборках ID нет; см. [RELEASING.md](RELEASING.md).
